    Check the installation process

    Crossfire 2.0.1 needs a clean Freelancer installation and no FLMM. After the installer, start the existing launcher, which downloads the new one. Compare your steps with the guide.

    Installation & requirements

    Make your support request count.

    If the checks do not help, complete this template and attach the support package from the launcher to your forum post.

    Four steps to a useful bug report

    1. 1

      Reproduce the issue and note the exact message.

    2. 2

      Enable Verbose logging before retrying, if more detail is needed.

    3. 3

      In the launcher, use Log → Support Package... to create the ZIP.

    4. 4

      Attach the ZIP in the support forum and describe the reproduction steps.
