File locations

Persistent log files and crash dumps are stored in the launcher's folder.

CFLauncher/
├─launcher.log
current persistent launcher log
├─launcher.log.old
previous rotated log
└─CrashDumps/opt-in
crash dumps, only if collection is enabled
Tip: the Log window shows what is happening now; these files keep the record after the launcher is closed.

4

What to upload to support

Follow these steps when reporting an issue.

  1. 1

    Reproduce the issue

    Enable Verbose logging first if needed.

  2. 2

    Create a support package

    Use Log → Support Package... to generate the ZIP file.

  3. 3

    Upload the ZIP file

    Attach the generated file to your bug report.

    CrossfireSupport_YYYYMMDD_HHMMSS.zip
  4. 4

    Add details

    Write short reproduction steps and when the issue happened.
